# Release Notes

## 11.0.0 — 2026-10-03

### Added

- Introduced CodeScope as a read-only CLI for AI-assisted repository reviews, focused suggestions, and token estimates.
- Added review profiles for architecture, security, reliability, performance, API design, dependencies, conventions, and release readiness, plus comprehensive reviews.
- Added custom prompts, model and reasoning-effort selection, usage reporting, and dry-run estimates.
- Added supplied-evidence handling that leaves reviewed repositories unchanged and never runs their commands or tests.
